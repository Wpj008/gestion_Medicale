# Système de gestion des dossiers médicaux

Ce projet est une application web destinée à la gestion des dossiers médicaux des patients.  
Il permet de centraliser, consulter et gérer les informations médicales de manière structurée.

## Fonctionnalités
- Gestion des patients (ajout, modification, suppression)
- Création et consultation des dossiers médicaux
- Suivi des informations médicales
- Interface utilisateur simple et intuitive

## Technologies utilisées
- PHP
- HTML
- CSS
- JavaScript
- MySql

## Objectif
Faciliter la gestion et l’organisation des dossiers médicaux dans un environnement numérique.
